Where the code and the guides disagree (checked %%DATE%%)

  1. scripts/lcodb_daily.sh suggests a 09:30 UTC cron, and config/ava_config.yaml has pipeline.prefect.schedule_cron: "30 10 * * *" "after lcodb daily (09:30)". Both guides use 01:00 and 02:00.
  2. pipeline.prefect.nightly_steps in the config is download_data, extract, calibrate_data, plot, publish: no PyTICS and no spectroscopy. The deployment guide (§7.3) lists the full set as "to set"; scripts/deploy.py without flags would deploy the short list.
  3. Job 3 is described two ways: as a Prefect deployment with a server and worker (deployment guide §7.3) and as a plain cron line running run_pipeline.py at 02:00 (linux_setup §17). Pick one for production.
  4. The clean-up cron line has --live in the deployment guide (§7.4) and not in linux_setup §17 (dry run until checked). Intended, but the guides should say which is the final form.
  5. Deployment guide §6.1 says data/literature/ is not in git and must be copied with ava.db. The CSVs and build/ scripts are in git (only cache/ is ignored), as linux_setup step 7 says.
  6. run_pipeline.py -m / -s (CALI merge) are still offered, but the task raises "merge task not yet ported". Neither guide mentions them.
  7. The -w step also recomputes the per-band F_var (as -t does); the guide's table lists only derived properties, observing flag, web copy and releases.
  8. The guides list the ADS host for the publications page; the website only links to ADS. The ADS API is used by the literature build (data/literature/build/).
