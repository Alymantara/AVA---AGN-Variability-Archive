\subsection{Injection test with a partner}
\label{sec:cr_pair_inject}
The injection test of Section~\ref{sec:cr_inject} was repeated on eight frames that have a partner (four NGC\,4151 at
OGG, four Fairall\,9 at COJ, two random seeds each, 20 hits per category per frame), injecting into one exposure only,
as real cosmic rays are, and reducing it with the 1.1.0 detector, with LA Cosmic and the object model, and with the
same-visit check added (Table~\ref{tab:cr_pair_inject}).

With the strict rule for new groups the comparison finds the same hits as the object model alone: of the 953
hits, none is found only with it, and 2 are found only without it, both faint hits on Fairall\,9 line peaks
(3.7--5$\sigma$, 7--12 per cent of the line). The 8
hits above 10$\sigma$ that both miss on the OGG peaks carry 4--38 per cent of the line under them. An earlier version
of the check, with the loose rule for new groups, found 14 more hits on the sky and 6 more on the line peaks, but the
same rule added hundreds of false pixels on the narrow lines of the real sample (Section~\ref{sec:cr_pair}); we chose
the clean lines. What the comparison does is remove flags: 22 per cent fewer pixels at OGG and 10 per cent fewer at
COJ in the frames without injected hits. It removes 9--19 LA Cosmic groups per frame that the partner shows to be real
structure and adds 0--1; 35--51 groups per frame stay flagged because the partner cannot check them. These runs were
made before the rule for pixels flagged in both exposures on the object; the rule acts only where the partner flagged
the same pixel, and an injected hit is in one exposure only, so it does not change which hits are found.
